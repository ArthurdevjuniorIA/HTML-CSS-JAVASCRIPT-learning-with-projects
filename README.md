# 🚀 HTML, CSS & JavaScript - Learning with Projects

Este repositório reúne os meus estudos, exercícios e projetos práticos focados no desenvolvimento web front-end utilizando **HTML5**, **CSS3** e **JavaScript**.

O objetivo deste repositório é documentar a minha evolução, aplicar conceitos teóricos na prática e manter um histórico organizado da minha jornada de aprendizagem.

---

## 📁 Estrutura do Repositório

O projeto está organizado nas seguintes pastas:

* 📄 **`HTML/`**: Exercícios, marcações estruturais e práticas focadas em HTML5.
* 📜 **`Javascript scripts/`**: Scripts e pequenos algoritmos em JavaScript para treinar lógica de programação, manipulação de dados e DOM.
* 🌐 **`Meu site pessoal/`**: Projeto prático de um site pessoal/portfólio em desenvolvimento.
* 🎨 **`Meu site, minhas regras/`**: Projetos de páginas web focados em estilização, layout e experimentações de design com CSS.
* ⚡ **`Projetos básicos em JavaScript/`**: Aplicações práticas e interativas utilizando JavaScript puro.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5**: Estruturação semântica de páginas web.
* **CSS3**: Estilização, layouts responsivos e design.
* **JavaScript (ES6+)**: Lógica de programação e interatividade no front-end.
* **Git & GitHub**: Controlo de versões e alojamento do código.
